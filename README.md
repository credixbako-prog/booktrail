# À trois — Carnet de voyage

Web app personnelle pour le premier voyage à Majorque en famille, du 27 août au 2 septembre 2026.

- itinéraire modifiable
- photos locales
- journal
- premières fois de bébé
- notes vocales via HTTPS
- export PDF et sauvegarde JSON

Les données personnelles restent dans le navigateur de l’appareil dans cette V1.
